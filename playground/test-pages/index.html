E2E Test Pages for Internal APIs & Security Boundaries

About Test Pages

This directory contains dedicated test pages for automated e2e testing of internal APIs, security boundaries, and edge cases. These pages are developer-facing utilities, not user-facing examples.

  • Test internal API security boundaries
  • Validate error handling and edge cases
  • Provide utilities for automated TestCafe tests
  • Expose APIs globally for browser-side testing
